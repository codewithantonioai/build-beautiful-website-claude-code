# Lesson 3 · Plan before you build

▶ [Watch this lesson](https://youtu.be/I7fLoe1TJZo?t=321) (starts at 5:21)

## Goal

Lesson three. Plan before you build, and let Claude interview you.

## Commands and files (as shown in the video)

### Terminal · brief

```bash
# ❯ I run a small neighborhood bakery called Marigold Bakery. I want a website for it, but I don't know how to
# code. It needs a home page, our menu with prices, an about page with our story, and a contact page with
# opening hours and our address. Keep it simple: plain files I can open in a browser, no build tools. Ask me
# anything you need before you start.
```

## Recap

So: plan mode reads and proposes, without touching anything. Let Claude interview you, it asks better questions than you'd think. And only when you approve does it build. Now, let's make it beautiful.
